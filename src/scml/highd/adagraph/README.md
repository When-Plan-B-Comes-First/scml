# AdaGraph (coming soon)

AdaGraph is the high-dimensional clustering algorithm of the SC-ML paradigm —
the high-D counterpart to AdaBox. It carries the adaptive, structure-centric
clustering idea from 2-D density boxes to graph-structured and
high-dimensional data.

**Status:** preprint available; reference implementation in preparation.
