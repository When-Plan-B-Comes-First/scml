# DA-Sampler (coming soon)

DA-Sampler (Density-Adaptive Sampler) is the high-D sampling component that
feeds the high-D SLCD workflow (Sample -> Learn -> Classify -> Deploy),
analogous to the stratified sampling used in the low-D track. It produces
samples that preserve cluster structure in high-dimensional spaces.

**Status:** preprint available; reference implementation in preparation.

**Preprint:** DA-Sampler is described as part of the high-D pipeline; see the
AdaGraph preprint — <https://arxiv.org/abs/2605.16320>
