# DA-Sampler (coming soon)

DA-Sampler (Density-Adaptive Sampler) is the high-D sampling component that
feeds the high-D SLCD workflow, analogous to the stratified sampling used in
the low-D track. It produces calibration samples that preserve cluster
structure in high-dimensional spaces.

**Status:** preprint available; reference implementation in preparation.
